Conectar o Claude

O Claude (claude.ai) está pedindo acesso à aba Assistente do seu painel.

  • Ler e escrever pendências, compras/indicações e lembretes
  • Ler e salvar o prompt de passagem
  • Nada do resto do painel (financeiro, clientes, marcas, e-mails…)
  • Apagar qualquer coisa

Só clique em Permitir se foi você que acabou de adicionar ou reconectar o conector no claude.ai. Se você recebeu este link de outra pessoa, clique em Negar.

Conector do Claude

Para conectar, adicione o conector nas configurações do claude.ai: esta página abre sozinha na hora certa.

Aqui você pode desconectar o Claude: todos os acessos dados até hoje param de funcionar na hora. Depois é só conectar de novo no claude.ai, se quiser.
